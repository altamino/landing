iOS 14.0 - 16.6.1, 16.7 RC (20H18), 17.0

Non-official stores

This method can help you make installation on iOS easier, although it have own limits.

1. Install AltStore Classic, SideStore or Scarlet using manuals (clicking on them brings you to official manuals; if using Scarlet beware of ads, use adblock dns of some kind).

2. Open app store you installed and add source:
- altamino.top/repo/altstore for SideStore/AltStore Classic
- altamino.top/repo/scarlet for Scarlet

3. Install AltAmino like an usual app.

iOS 15.0+
